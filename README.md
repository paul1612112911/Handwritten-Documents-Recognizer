# 手寫文件辨識系統
## 如何運行此程式
1. 安裝[uv](https://docs.astral.sh/uv/getting-started/installation/) (uv角色類似anaconda，可進行python專案與虛擬環境管理)，並加入到PATH環境變數
2. 使用終端機切換工作目錄到此根目錄
3. `uv sync`
4. 使用`uv run main.py`執行程式

## 程式操作步驟
1. 點"載入模板"
2. 選擇document images內的template圖片，這是一張空白表格。
3. 選擇你要的模型，選完之後框選目標的表格(滑鼠點一下是框框的一個角落，點第二下是另一個角落)，框框要超出表格範圍但盡量貼近表格。辨識框選的表格所使用的模型，是在框選時左側勾選的模型。
4. 點"清除"可以清除目前所框的所有選擇，重新框選。
5. 點"辨識圖片檔案"，根據你所選的模型類型，選擇相應的手寫表格圖片。
6. 等他跑完之後，左邊會在模板印上辨識出的數字，右邊是原本的圖片，如果同時辨識多張圖片，用滑鼠滾輪切換辨識文件。點擊左邊圖辨識結果的表格欄位可以修改結果。
7. 點擊"結束編輯並儲存"來儲存辨識結果，它是一個excel檔。
8. 回到3.的狀態。
